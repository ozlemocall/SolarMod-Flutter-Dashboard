

# ☀️ SolarMod - Güneş Paneli Kontrol Merkezi (Flutter)

## 🚀 Öne Çıkan Özellikler

* **Canlı Enerji Takibi:** Üretim, tüketim ve sistem verimliliği değerlerinin anlık izlenmesi.
* **Akıllı Verimlilik Algoritması:** Panel verimliliği kritik bir eşiğin altına düştüğünde kullanıcıya otomatik temizleme uyarısı gönderen sistem.
* **Panel Eğim Kontrolü:** Panellerin güneş açısına göre yönlendirilmesini sağlayan interaktif kontrol butonları.
* **Enerji Akış Diyagramı:** Güneş paneli, batarya ve ev arasındaki enerji transferini görselleştiren canlı akış şeması.

## 🛠️ Teknik Detaylar
* **Framework:** Flutter (Dart)
* **Hata Yönetimi:** `WidgetsBinding.instance.addPostFrameCallback` ile güvenli UI güncellemeleri.
